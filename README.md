# Data Professional Survey Dashboard (Power BI)

An end-to-end Power BI project analyzing a survey of 600+ data professionals — covering salaries, programming language popularity, work-life balance, and career entry difficulty. Built by following Alex the Analyst's Power BI tutorial series and adapted for portfolio use.

---

##  Project Overview

This project takes raw survey data from over 600 data professionals through a full Power BI workflow — cleaning and transforming the data, calculating key metrics with DAX, and building an interactive, polished dashboard covering compensation, tools, and career satisfaction across the data field.

##  Tools Used

- **Power BI Desktop** — data modeling, DAX, visualization
- **Power BI Service** — publishing/sharing
- **Dataset** — survey of 600+ data professionals

##  Process

**1. Data Preparation & Cleaning**
Imported the raw survey data into Power BI, removed unnecessary columns, and split columns (like job titles and programming languages) using delimiters to standardize the values. Built an **Average Salary** column using DAX by averaging the given salary ranges.

**2. Building Visualizations**
- **Cards** — high-level metrics like total survey respondents and average age
- **Bar/Column Charts** — average salary by job title, and popularity of programming languages
- **Tree Map** — respondents categorized by country
- **Gauges** — average ratings for work-life balance and salary satisfaction
- **Donut Chart** — average salary comparison by gender
- **Additional chart** — perceived difficulty of breaking into the data field

**3. Refining & Formatting**
Cleaned up the dashboard layout, renamed titles for clarity, adjusted colors for readability, and applied a Power BI theme to improve the overall look and consistency of the final report.

##  Key Takeaways

- Splitting and standardizing messy survey columns early makes every visualization downstream far more reliable.
- DAX calculated columns (like average salary from a range) turn raw survey inputs into usable metrics.
- Visual variety (cards, gauges, tree maps, donuts) helps different types of insights land clearly instead of forcing everything into one chart type.
- Formatting and theming at the end meaningfully improves how professional the final dashboard looks and reads.
